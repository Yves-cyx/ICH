# 影间非遗

中国非物质文化遗产课程展示应用。注册或登录后，可以浏览非遗目录、查看图文详情，用戏台和展馆认识影偶，也可以设计皮影并保存到个人档案。

## 目录

| 路径 | 内容 |
| --- | --- |
| `android/` | Android 客户端，Java、XML、ConstraintLayout、ViewBinding、Material 3、MVVM |
| `server/` | Spring Boot REST API，Java、Maven、Spring Security、JWT、MyBatis-Plus |
| `database/init.sql` | MySQL 8 建表和六条可浏览的非遗目录数据 |
| `docs/openapi.json` | 从运行中的服务导出的 OpenAPI 接口描述 |
| `scripts/smoke-api.py` | 通过真实 HTTP 和测试账号验证端到端接口 |

## 1. 初始化 MySQL

需要 MySQL 8、JDK 17 或 21、Maven 3.9 及 Android SDK 34。请以 MySQL 管理员执行 `database/init.sql`。然后为 API 创建专用账号，以下密码请替换为自己的随机密码。

```sh
mysql -u root -p < database/init.sql
```

```sql
CREATE USER 'feiyi'@'127.0.0.1' IDENTIFIED BY 'replace-with-a-unique-strong-password';
GRANT SELECT, INSERT, UPDATE, DELETE ON feiyi.* TO 'feiyi'@'127.0.0.1';
```

## 2. 启动服务

```sh
export DB_URL='jdbc:mysql://127.0.0.1:3306/feiyi'
export DB_USER='feiyi'
printf 'MySQL password: '
stty -echo
read -r DB_PASSWORD
stty echo
printf '\n'
export DB_PASSWORD
export JWT_SECRET="$(openssl rand -hex 32)"

mvn -f server/pom.xml package
java -jar server/target/feiyi-server-1.0.0.jar
```

将 `JWT_SECRET` 保存在部署环境的密钥配置中，重启时复用同一个密钥可以让已有令牌在有效期内继续使用。服务默认监听 `127.0.0.1:8096`。可以用 `SERVER_PORT` 和 `SERVER_ADDRESS` 配置监听地址。远程部署请使用 HTTPS，并给 MySQL 使用专用账户。

- Swagger UI：[http://127.0.0.1:8096/swagger-ui.html](http://127.0.0.1:8096/swagger-ui.html)
- OpenAPI JSON：[http://127.0.0.1:8096/v3/api-docs](http://127.0.0.1:8096/v3/api-docs)
- 初次使用在客户端点击「创建账号」。服务使用 BCrypt 存储密码哈希，个人资料和作品按 JWT 用户身份隔离。

## 3. 构建与运行 Android

用 Android Studio 打开 `android/`，将 Gradle JDK 设为 17 或 21，并安装 Android SDK Platform 34。也可通过 `ANDROID_HOME` 或 `local.properties` 指定 Android SDK 路径。

```sh
(cd android && ./gradlew :app:assembleDebug :app:lintDebug)
```

调试包位于 `android/app/build/outputs/apk/debug/app-debug.apk`，支持 Android 7.0 及以上。Android Studio 的模拟器通过 `http://10.0.2.2:8096/` 访问本机服务。

连接 USB 真机时，可以把设备回环端口转发给电脑。请构建并安装同一次命令生成的 APK。

```sh
adb reverse tcp:8096 tcp:8096
(cd android && ./gradlew :app:assembleDebug -PFEIYI_API_URL=http://127.0.0.1:8096/)
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

远程部署时构建参数设为实际服务的 HTTPS 地址，末尾保留斜杠。App 的调试配置仅对模拟器和设备回环地址开放 HTTP。

## 4. 接口与验证

```sh
API_BASE=http://127.0.0.1:8096 python3 scripts/smoke-api.py
```

| 方法及路径 | 功能 | 访问 |
| --- | --- | --- |
| `POST /api/auth/register`、`POST /api/auth/login` | 注册和登录，返回 Bearer JWT | 公开 |
| `GET /api/heritage`、`GET /api/heritage/{id}` | 非遗目录和详情 | 公开 |
| `GET /api/me`、`PUT /api/me` | 读取和编辑个人资料 | 登录 |
| `GET /api/works`、`POST /api/works` | 查看和创建本账号的作品 | 登录 |
| `PUT /api/works/{id}`、`DELETE /api/works/{id}` | 修改或删除本账号的作品 | 登录 |

业务响应使用 `code`、`message` 和 `data`，成功时 `code` 为 0，失败时和 HTTP 状态码一致。常见失败包括参数不合法（400）、未登录或令牌失效（401）、权限不足（403）、内容不存在（404）、账号已注册（409）。请在受保护接口发送 `Authorization: Bearer <token>`。JWT 在 12 小时后过期。

Room 缓存已同步的公共非遗目录及其介绍。注册、编辑资料和同步作品时需要能连接服务器。

## 扩展功能

新增后端业务时，在对应的 Controller 定义接口，由 Service 实现规则、Mapper 访问数据库。Android 端在 `FeiyiApi` 声明请求，Repository 负责网络和缓存，ViewModel 将页面状态交给使用 ViewBinding 的界面。修改持久化结构时，为已有 MySQL 表和 Room 缓存提供对应的迁移。
