# 设计与素材规范

## 视觉方向

暖白幕布、深墨文字、朱红重点、少量金色装饰。图鉴大图与清晰排版建立第一印象；体验界面突出影人和操作反馈。

| Token | 色值 | 用途 |
| --- | --- | --- |
| ich_paper | #F5EFE3 | 页面底色 |
| ich_ink | #25211E | 主要文字 |
| ich_red | #A83929 | 选中状态、主操作 |
| ich_gold | #B68A50 | 细节装饰 |

正文优先可读性，字号用 sp；触控区域至少 48dp。装饰动画短且可跳过，不阻塞首次操作。暖光戏台作为皮影体验重点视觉，不将 50 类非遗全部包装成皮影。

## 素材登记

每项记录：assetId、用途、文件路径、来源链接、作者、许可/授权状态、修改方式、负责人。待授权素材不能当作最终交付资产。
百科文字自行整理并注明出处；AI 图片标明示意，不用作真实文物或工艺史实证据。

## 运行素材

- 360°：同一模型/机位距离/光照/尺寸，36 个等角度帧；命名 frame_000.webp 至 frame_035.webp。A 先定尺寸与内存预算，再批量渲染。
- 皮影：B 先给部件清单、关节锚点和画布坐标约定，再切图，避免整张图无法做关节动作。
- 临摹：透明或浅色背景底图，并标注参考画布比例。
- 不上传大体积原始 3D 工程或渲染缓存。原始工程保存到团队约定位置，在素材登记中留可访问地址。
