# 启动指南

## 本地启动

按 [影间非遗运行指南](影间非遗运行指南.md) 初始化数据库并启动后端，再用 Android Studio 打开 `android/`，运行 `app`。
使用 JDK 17 或 21、Android SDK Platform 34 和 Build Tools 34.0.0。启动后可以创建账号或登录。

命令行构建和检查（从仓库根目录运行）：

```bash
cd android
./gradlew assembleDebug lintDebug
```

Windows PowerShell 使用 `.\gradlew.bat assembleDebug lintDebug`。调试 APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`。

## 三人启动验收

每人在启动 Issue 记录：系统、Android Studio / JDK 版本、设备 API、构建结果、三入口截图。环境检查 T00 以三人均通过为完成条件；M0 还需 A 完成 T09 框架交接。

## CI

GitHub Actions 在 PR 与 main 推送运行 assembleDebug 与 lintDebug，并保存 Debug APK。
CI 编译成功不代表真机交互验收通过。仓库管理员仍需在 GitHub 设置中自行启用需要的分支保护。
