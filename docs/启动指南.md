# 启动指南

## Android

1. 安装 Android Studio，克隆仓库；选择 Open 打开 android/，而不是仓库根目录。
2. 使用 JDK 17 或 21 作为 Gradle JDK；三人约定同一个版本，建议 21。
3. 在 SDK Manager 安装 Android SDK Platform 36 和相应构建工具；由 Gradle 下载项目依赖。
4. 等待 Gradle Sync，创建 API 24 或更高的模拟器，或连接 Android 真机，运行 app。
5. 应看到暖白背景、ICH 标题与“非遗图鉴 / 体验 / 我的”三个可切换入口。

当前固定 AGP 8.13.0、Gradle 8.13、compileSdk/targetSdk 36、minSdk 24；Java 源码级别 11。更改版本需团队统一。
Wrapper 脚本与 jar 已纳入仓库。不要提交自己电脑的 SDK 路径。

命令行（先进入 android）：
```bash
./gradlew assembleDebug lintDebug
```

Windows PowerShell：
```powershell
.\gradlew.bat assembleDebug lintDebug
```

Debug APK 输出：android/app/build/outputs/apk/debug/app-debug.apk。
下载失败先检查网络/代理与 SDK 安装；不要为了下载问题随意更换版本。

运行后点“非遗图鉴 → 皮影戏 · 查看详情”，应能看到编号 shadow-puppetry。完整的八个页面、登录表单和返回路径见[框架交接清单](A的框架开发指南.md)。

## 三人启动验收

每人在启动 Issue 记录：系统、Android Studio / JDK 版本、设备 API、构建结果、三入口截图。环境检查 T00 以三人均通过为完成条件；M0 还需 A 完成 T09 框架交接。

## CI

GitHub Actions 在 PR 与 main 推送运行 assembleDebug 与 lintDebug，并保存 Debug APK。
CI 编译成功不代表真机交互验收通过。仓库管理员仍需在 GitHub 设置中自行启用需要的分支保护。
