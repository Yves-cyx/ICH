# 影间非遗统一接口文档

契约版本 1.0.0。Android 与后端统一使用 `/api` 路径、数字资源 ID 和 `code/message/data` 响应。每项接口标注 **已实现** 或 **待实现**。可导入 Swagger Editor 或 Postman 的版本见[统一 OpenAPI 3.1](openapi-contract.json)。运行中的后端通过 `/v3/api-docs` 提供已实现接口。 [功能清单](功能清单.md) · [已实现接口快照](openapi.json)

## 通用协议

| 项目 | 约定 |
| --- | --- |
| 调试地址 | 电脑本机 `http://127.0.0.1:8096`，Android 模拟器 `http://10.0.2.2:8096`。USB 真机连接见部署说明。 |
| 请求与响应 | JSON UTF-8。带 JSON 请求体时用 `Content-Type: application/json`，字段使用 camelCase。 |
| 鉴权 | 登录或注册返回 `data.token`。受保护请求发送 `Authorization: Bearer <token>`。JWT 有效期 12 小时。 |
| 资源标识 | 图鉴和账户皮影作品的 ID 为正整数，Android 使用 `Long`。题库与素材键使用独立的字符串字段。 |
| 时间 | 新接口的时间使用 UTC 的 RFC 3339 格式，例如 `2026-11-23T12:00:00Z`。 |
| 列表 | `data` 为数组，空结果返回 `[]`。规划中的分页使用 `page`、`size` 和响应头 `X-Total-Count`。 |
| 私有资源 | 个人资料、作品、收藏、测评结果和设置按 JWT 当前账号处理。请求体无需用户 ID。 |

~~~json
{"code":0,"message":"成功","data":{"id":1}}
{"code":404,"message":"该非遗项目不存在","data":null}
~~~

成功使用 HTTP 200 或 201，`code` 为 0。无业务数据时 `data` 为 `null`。失败时 `code` 和 HTTP 状态码一致，`data` 为 `null`。客户端按状态码和 `code` 判断结果，`message` 用于展示。

| HTTP 状态 | 含义 |
| --- | --- |
| 200、201 | 请求完成、资源创建成功 |
| 400 | 参数校验失败或请求体格式错误 |
| 401、403 | 认证失败、权限不足 |
| 404 | 资源不存在，或当前账号查不到该私有资源 |
| 405、415 | 请求方法或媒体类型不受支持 |
| 409 | 重复注册、规划中的题库版本冲突 |
| 500 | 服务内部异常 |

## 账号与会话

| 状态 | 方法及路径 | 鉴权 | 请求 | 成功 |
| --- | --- | --- | --- | --- |
| 已实现 | `POST /api/auth/register` | 公开 | `Credentials` | 201，`Token`。注册成功即取得会话，账号重复返回 409 |
| 已实现 | `POST /api/auth/login` | 公开 | `Credentials` | 200，`Token`。凭据错误返回 401 |
| 待实现 | `PUT /api/me/password` | JWT | `PasswordChange` | 200，`null`。当前密码错误返回 400，成功后要求重新登录 |

- `Credentials` 必填 `username`、`password`。账号为 3–24 位英文字母、数字或下划线，服务端按小写匹配。密码至少 8 个字符且最多 72 个 UTF-8 字节。
- `Token` 的字段为 `token: string`，例如 `{"token":"<jwt>"}`。
- 当前退出登录由客户端清除本地令牌。已签发的令牌到期失效。规划中的修改密码要求后端让该账号旧令牌失效。
- `PasswordChange` 必填 `currentPassword`、`newPassword`，密码格式沿用上述规则，新旧密码须不同。

## 图鉴与搜索

| 状态 | 方法及路径 | 鉴权 | 请求 | 成功 |
| --- | --- | --- | --- | --- |
| 已实现 | `GET /api/heritage` | 公开 | 可选 `keyword`、`category`、`page`、`size` | 200，`Heritage[]`，按 `id` 升序，分页时附总数响应头 |
| 已实现 | `GET /api/heritage/{id}` | 公开 | 路径参数 `id` | 200，`Heritage`。条目不存在返回 404 |

- `keyword` 去除首尾空白，最长 80 字符，对标题、地区、简介做包含匹配。空关键词视为未筛选，输入的 SQL 通配符按普通字符匹配。
- `category` 支持 `表演`、`工艺`、`音乐`。省略表示全部，与关键词同时传入时取交集。
- `page` 从 1 开始，`size` 为 1–50。传入时须为整数，空值或越界返回 400。任一分页参数出现即启用分页，默认页码 1、页大小 20。响应头 `X-Total-Count` 为筛选后的总条数。省略两个分页参数时返回匹配的完整数组，兼容 Android 的全量缓存。
- 示例请求为 `GET /api/heritage?keyword=皮影&category=表演&page=1&size=20`。发送时由 HTTP 客户端编码中文参数。

| Heritage 字段 | 类型 | 状态与含义 |
| --- | --- | --- |
| `id` | integer int64 | 已实现，稳定条目 ID |
| `title`、`category`、`region` | string | 已实现，标题、类别、地区 |
| `summary`、`description` | string | 已实现，简介和详情正文 |
| `artKey` | string | 已实现，Android 内置插画键 |
| `coverUrl` | string URL 或 null | 待实现，可缺省。有封面时使用封面，否则按 `artKey` 渲染 |
| `features`、`background` | string | 待实现，可缺省。工艺或表演特点、文化背景 |
| `sources` | `{title: string, url: string}[]` | 待实现，可缺省。正式内容应附至少一条来源 |
| `experiences` | `{type: string, assetId: string}[]` | 待实现，可缺省。类型为 `stage`、`viewer`、`drawing`，空数组表示无关联入口 |

~~~json
{
  "code": 0,
  "message": "成功",
  "data": {
    "id": 1,
    "title": "中国皮影戏",
    "category": "表演",
    "region": "陕西 · 华县",
    "summary": "一盏灯、一方幕，演出千百年的故事。",
    "description": "皮影戏以兽皮或纸板制成的影偶为主角。",
    "artKey": "shadow"
  }
}
~~~

## 收藏

| 状态 | 方法及路径 | 鉴权 | 请求 | 成功 |
| --- | --- | --- | --- | --- |
| 已实现 | `GET /api/me/favorites` | JWT | 可选 `page`、`size` | 200，`Heritage[]`，分页时附总数响应头 |
| 已实现 | `PUT /api/me/favorites/{heritageId}` | JWT | 路径参数 `heritageId` | 200，`null`。已收藏时重复提交仍成功 |
| 已实现 | `DELETE /api/me/favorites/{heritageId}` | JWT | 路径参数 `heritageId` | 200，`null`。已取消时重复提交仍成功 |

列表按收藏时间倒序，时间相同按条目 ID 倒序，分页规则和图鉴一致。加入收藏时条目不存在返回 404。详情页可读取当前账号未分页的收藏列表，用 ID 集合显示按钮状态。收藏操作成功后更新集合，重新登录或进入「我的收藏」时同步。

### Android 数据层交接

界面在后台线程调用 `Repository.searchCatalog(keyword, category, page, size)` 查询图鉴，以及 `listFavorites(token, page, size)`、`addFavorite(token, heritageId)`、`removeFavorite(token, heritageId)` 管理收藏。列表调用返回 `HeritagePage`，其中 `items` 为结果数组，省略分页时 `totalCount` 为 `null`。搜索结果单独返回，全量目录仍由 `refreshCatalog()` 更新离线缓存。

## 个人资料与皮影作品

| 状态 | 方法及路径 | 鉴权 | 请求 | 成功 |
| --- | --- | --- | --- | --- |
| 已实现 | `GET /api/me` | JWT | 无 | 200，`Profile` |
| 已实现 | `PUT /api/me` | JWT | `ProfileInput` | 200，更新后的 `Profile` |
| 已实现 | `GET /api/works` | JWT | 无 | 200，`Work[]`，按作品 ID 倒序 |
| 已实现 | `POST /api/works` | JWT | `WorkInput` | 201，创建的 `Work` |
| 已实现 | `PUT /api/works/{id}` | JWT | 路径参数 `id` 和完整 `WorkInput` | 200，更新后的 `Work`。查不到本账号作品返回 404 |
| 已实现 | `DELETE /api/works/{id}` | JWT | 路径参数 `id` | 200，`null`。查不到本账号作品返回 404 |

- `Profile` 包含 `username`、`nickname`、`bio`。`ProfileInput` 必填 `nickname` 和 `bio`。昵称须非空，最长 24 字符。简介可为空字符串，最长 160 字符。
- `WorkInput` 必填 `name`、`shape`、`palette`、`x`、`y`、`angle`。名称去除首尾空白后须非空，长度上限 32。角色为 `scholar`、`warrior`、`lady`，配色为 `cinnabar`、`indigo`、`amber`。
- `x`、`y` 为归一化坐标，范围分别为 0.08–0.92 和 0.22–0.78。`angle` 以度为单位，范围 −45 至 45。`Work` 在这些字段外带数字 `id`。Android 可以用列表返回的作品直接进入编辑器。

~~~http
POST /api/works
Authorization: Bearer <token>
Content-Type: application/json

{"name":"我的第一件皮影","shape":"scholar","palette":"cinnabar","x":0.5,"y":0.54,"angle":0}
~~~

## 个人非遗性格、AI 助手与美化设置

以下接口均为 **待实现**。非遗性格按问答测评约定，题库内容、结果类型和计分规则待项目组确认。美化与 AI 助手偏好按账号保存。

| 状态 | 方法及路径 | 鉴权 | 请求 | 成功 |
| --- | --- | --- | --- | --- |
| 待实现 | `GET /api/heritage-personality/questions` | 公开 | 无 | 200，`PersonalityQuiz` |
| 待实现 | `GET /api/me/heritage-personality` | JWT | 无 | 200，`PersonalityResult`。尚未测评时为 `null` |
| 待实现 | `POST /api/me/heritage-personality` | JWT | `PersonalityAnswers` | 200，计算并保存的 `PersonalityResult`。题库版本过期返回 409 |
| 待实现 | `GET /api/me/preferences` | JWT | 无 | 200，`Preferences`。首次读取提供默认值 |
| 待实现 | `PATCH /api/me/preferences` | JWT | `PreferencesPatch`，至少提交一个具体字段 | 200，更新后的完整 `Preferences` |

- `PersonalityQuiz` 包含 `quizVersion: string` 和 `questions: {id, text, options: {id, text}[]}[]`。题目和选项 ID 均为字符串。
- `PersonalityAnswers` 包含 `quizVersion` 和 `answers: {questionId, optionId}[]`。每道题恰好提交一个属于该题的选项。缺题、重复或非法选项返回 400。
- `PersonalityResult` 包含 `quizVersion`、`typeCode`、`title`、`description`、`completedAt`。服务端计算结果，并保存当前账号最近一次结果。
- `Preferences` 包含 `appearance` 和 `assistant`。PATCH 合并已提交的具体字段，省略字段保留原值。空修改或非法枚举返回 400。

| 偏好字段 | 取值 | 默认值 |
| --- | --- | --- |
| `appearance.themeMode` | `system`、`light`、`dark` | `system` |
| `appearance.accentColor` | `cinnabar`、`indigo`、`amber` | `cinnabar` |
| `assistant.enabled` | boolean | `false` |
| `assistant.responseStyle` | `brief`、`detailed` | `brief` |

~~~http
PATCH /api/me/preferences
Authorization: Bearer <token>
Content-Type: application/json

{"appearance":{"themeMode":"dark"},"assistant":{"enabled":true}}
~~~

## 客户端功能与作品格式

- 体验卡片、戏台灯光、影人操控、内置展馆和首版 360° 序列播放由 Android 处理。账户皮影设计的读取和写入使用作品接口。
- 临摹草稿采用本地版本化 `DrawingDocument`，包含底图、画布宽高比和归一化笔画。计划中的「我的作品」可在客户端汇总本地临摹和账户皮影。当前作品接口接收皮影设计字段。 [本地作品契约](https://github.com/Yves-cyx/ICH/blob/fa82762/contracts/works.md)
- AI 助手当前约定开关与回答偏好。聊天接口在会话范围确定后另行约定。

## 早期草案迁移

| 早期草案 | 统一后的约定 |
| --- | --- |
| `/api/v1/heritages`、`/api/v1/heritages/{id}` | `/api/heritage`、`/api/heritage/{id}` |
| 图鉴字符串 ID、`name`、列表 `items` | 图鉴数字 ID、`title`、列表 `data: []` |
| 登录返回 `accessToken` 和内嵌 `user` | 登录及注册返回 `data.token`，个人资料使用 `GET /api/me` |
| `POST /api/v1/auth/logout` | 当前由客户端清除本地 JWT 会话 |
| 收藏变更返回 204 | 使用 HTTP 200 和 `{"code":0,"message":"成功","data":null}` |
| 字符串错误码 | `code` 用数字，失败时和 HTTP 状态一致 |

接口变更在同一 PR 更新统一 OpenAPI、客户端调用和对应业务验证。已有接口可使用[API 冒烟脚本](../scripts/smoke-api.py)验证。

接口来源见 [早期接口草案](https://github.com/Yves-cyx/ICH/blob/fa82762/contracts/api.md) · [当前后端 OpenAPI](https://github.com/Yves-cyx/ICH/blob/fa82762/docs/openapi.json) · [本地部署说明](../README.md)
