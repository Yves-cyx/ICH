# ICH · 非遗图鉴与互动体验

三人协作的 Android 课程项目。以 **非遗图鉴、互动体验、我的** 为三个入口，让用户了解非遗、动手体验并保存作品。

## 从这里开始

1. 阅读 [项目方案](项目.md)，确认首版范围。
2. 阅读 [三人分工](docs/分工.md)，认领 A / B / C。
3. 按 [启动指南](docs/启动指南.md) 运行 Android 骨架。
4. 在 [首批任务](docs/首批任务.md) 中选一个任务，按 [协作流程](CONTRIBUTING.md) 开分支。

## 当前状态

- 已提供：Java + XML 三入口启动骨架、协作约定、接口草案、示例数据、任务与 PR 模板。
- 界面是可继续开发的占位骨架；图鉴搜索、戏台、360° 查看、画布和账号功能尚未实现。
- 后端技术待 C 提案后确定；当前没有运行中的服务器。
- Android 构建以 GitHub Actions 和三位成员的本地运行结果为准；初始化时未在真机验收。

## 仓库结构

| 目录 | 内容 |
| --- | --- |
| `android/` | Android 工程；在 Android Studio 打开此目录 |
| `server/` | 后端实现入口，目前只有启动约定 |
| `contracts/` | 共享接口、示例数据与作品格式 |
| `docs/` | 分工、启动、设计、任务与素材规范 |
| `.github/` | Issue / PR 模板、构建工作流 |

## 协作约定

一个任务只有一位负责人；共享接口先约定再改；小分支、小 PR、每 1–2 天合并一次。
A 暂由陈翊轩负责，B / C 等两位成员认领。实际截止日期待确认，里程碑先按验收条件推进。
